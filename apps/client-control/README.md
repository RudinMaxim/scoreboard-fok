# Client Control

Клиент для операторских экранов и программных пультов.

Планируемая зона ответственности:

- основная панель матча;
- пульт хронометриста;
- пульт оператора счета;
- CRUD экранов команд, игроков, матчей и игрового дня;
- системный статус, восстановление после сбоя и подтверждения критических действий.

## Docker

`Dockerfile` в этой директории является заготовкой production-образа `scoreboard-fok/client-control`.
Основной compose находится в `infrastructure/docker-compose.prod.yml`.
