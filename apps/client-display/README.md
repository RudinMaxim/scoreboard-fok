# Client Display

Клиент для вывода игрового табло на LED-экран через HDMI/VP410.

Планируемая зона ответственности:

- полноэкранный режим на втором экране;
- игровое табло, перерыв, разминка, составы, тестовый экран;
- отображение состояния, полученного от сервера;
- безопасные пустые и аварийные состояния.

## Docker

`Dockerfile` в этой директории является заготовкой production-образа `scoreboard-fok/client-display`.
Основной compose находится в `infrastructure/docker-compose.prod.yml`.
