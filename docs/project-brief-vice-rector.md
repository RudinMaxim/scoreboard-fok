# Электронное баскетбольное табло: краткая записка для проректора

## Суть проекта

Проект направлен на создание программно-аппаратного комплекса для проведения баскетбольных матчей в спортивном зале: LED-табло для зрителей, операторская панель, программные пульты управления временем и счётом, локальная база данных матчей, команд и игроков. Комплекс закрывает ключевые требования FIBA: игровое время, shot clock 24/14, счёт, фолы, тайм-ауты, владение, журнал событий и восстановление матча после сбоя.

Практический результат: зал получает управляемое электронное табло, пригодное для матчей уровня университетских, региональных и студенческих соревнований, без зависимости от внешнего интернета и с быстрым запуском игрового дня.

| --- | --- |
| Руководитель проекта / аналитик | требования, календарь, согласование с заказчиком, приёмка |
| Backend-разработчик | сервер, БД, WebSocket, таймеры, журнал событий |
| Frontend-разработчик | LED-экран, операторская панель, программные пульты |
| Инженер интеграции | VP410, физическое табло 24/14, проводные подключения, тесты в зале |
| QA / технический писатель | сценарии приёмки, проверка FIBA-логики, инструкции оператору и администратору |
